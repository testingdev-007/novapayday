Setup Guide v2
Personal accounts — no organisation, no Copilot Business needed
✓ You're using this one — Personal accounts
Org + Business version is a separate printable guide
Why this version exists: GitHub has paused new Copilot Business sign-ups for organisations on the Free/Team plan. This path sidesteps that completely — no organisation, no seats to manage, no waiting. Everything below happens on ordinary personal GitHub accounts.
0
Which accounts do you actually need?
This guide sets up your own account, and optionally one test account for Friday's run-through. On the real session day, every student creates their own account as normal — you are not creating accounts for them, and Copilot switches on automatically with zero action from you.
1
Get an email, if you need a second one
Skip if you're only setting up your own account
Only needed for a second test account. Go to gmail.com → Create account → follow the prompts (free, ~3 minutes)
2
Create your GitHub account(s)
Go to github.com → Sign up → enter email, password, username → verify with the emailed code
Repeat for the second email if setting up a test account too
3
Turn on Copilot — per account
Fully self-serve — nobody needs to approve or assign anything
Free is already active the moment the account exists — 2,000 completions + 50 chat messages/month, no card needed. You can skip straight to Part 4 and only come back here if you want more.
Upgrade your own account to Pro (recommended): profile photo → Settings → Copilot → Change plan → Copilot Pro → confirm ($10/month)
Leave the test account on Free for now — only upgrade it if the 50-message cap gets hit during testing
4
Build the workshop repo
On your personal account — no organisation involved
Click + → New repository → name it novapay-workshop → Public → tick Add a README → Create repository
Add file → Upload files → drag in bank-dashboard.html, starter-template.html, and challenge.js → Commit changes
Add file → Create new file → filename exactly:
.devcontainer/devcontainer.json
Paste in the config contents → Commit new file
Repo Settings → tick Template repository
One step you get to skip: the org path has a "set Copilot access to all repositories" policy step here. Personal accounts don't need it — Copilot just works everywhere on the account automatically.
5
Install Nova
Identical either way — this file doesn't care whether an org exists
Add file → Create new file → filename exactly:
.github/copilot-instructions.md
Paste in the full contents of copilot-instructions.md → Commit changes
Confirmed to work on Free, Pro, and Team plans — not a Business/Enterprise-only feature.
6
Test end-to-end
Do this on Friday
Repo → Use this template → Create a new repository → name it test-novapay
Code → Codespaces → Create codespace on main → wait for load
Right-click bank-dashboard.html → Open with Live Server → confirm it renders
Copilot Chat → type:
Who are you?
Should describe itself as a NovaPay mentor — not generic Copilot
Have a realistic number of back-and-forth chats — if you're nowhere near 50 messages on Free, you're set; if you're closing in fast, upgrade that account to Pro before the real day
Test repo → Settings → scroll down → Delete this repository
