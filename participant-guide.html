🐛 Workshop Guide
Let's get you set up
Follow these steps in order and you'll be fixing bugs in about 5 minutes.
👤
Step 1 — Create a GitHub account
Skip this if you already have one — just sign in
1
Go to github.com and sign up

Go to github.com → click Sign up. Enter an email address, create a password, choose a username.

Check your email — GitHub will send a verification code. Enter it to confirm your account.

✅If you already have a GitHub account, just sign in and go to Step 2.
🤖Copilot usually just switches on automatically once your account exists — nothing else to do. If your facilitator tells you to check your email for an org invite first, accept that before moving on.
Then
📁
Step 2 — Get your own copy of the code
You'll have your own workspace to break and fix freely
2
Go to the workshop repo

Type this URL into your browser — or click the link your facilitator puts on screen:

github.com/[FACILITATOR-USERNAME]/novapay-workshop
3
Make your own copy

On the repo page, click the green Use this template button → then Create a new repository.

Use this template → Create a new repository

Give it any name — something like my-novapay is fine. Make sure it's set to Public. Click Create repository.

💡This is now your own personal copy. Nobody else can change your code, and you can't break anyone else's.
Then
💻
Step 3 — Open your coding environment
This opens VS Code in your browser — no installs needed
4
Open a Codespace

On your new repo page, click the green Code button → click the Codespaces tab → click Create codespace on main.

Code ▾ → Codespaces tab → Create codespace on main

A new tab will open and start loading. This takes 1–2 minutes the first time — it's setting everything up for you in the background.

⏳Don't close the tab while it's loading. Just wait — it will finish.
5
Wait for it to finish setting up

When it's ready, you'll see a code editor in your browser that looks like this:

  • A file panel on the left showing bank-dashboard.html
  • A large empty editing area in the middle
  • A row of icons down the very left edge
✅If you see "Extensions installing…" at the bottom — that's fine, just wait another 30 seconds and it'll finish.
Then
🌐
Step 4 — Open the NovaPay dashboard
Preview the page you're about to fix
6
Open the dashboard in Live Server

In the file panel on the left, right-click on bank-dashboard.html → click Open with Live Server.

Right-click bank-dashboard.html → Open with Live Server

A new browser tab will open showing the NovaPay dashboard. Keep both tabs open — the code editor and the preview.

💡Live Server means the preview updates automatically every time you save a change. You'll see your fixes appear instantly.
👀Don't see "Open with Live Server"? Wait 30 seconds — the extension is still installing. Then try right-clicking again.
Then
🤖
Step 5 — Open Copilot Chat
Your AI coding assistant — use it throughout the bug hunt
7
Open the Copilot panel

Look at the row of icons on the very left edge of the editor. Click the Copilot icon — it looks like the GitHub Copilot logo (two diagonal lines forming a shape). The chat panel will open on the right.

Alternatively, press Ctrl+Shift+I on Windows or Cmd+Shift+I on Mac.

✅Type "hello" in the chat box and press Enter to confirm it responds. If it does, you're fully set up.
8
How to use Copilot during the bug hunt

You can ask Copilot anything in plain English. Here are some prompts that work well:

Are there any bugs in this code?
I clicked this button and nothing happened — what could cause that?
What does this function do?
Why might a number show up as NaN instead of a value?
How do I check if two IDs used in different places actually match?
Can you explain this CSS rule to me?
💡The more specific your question, the better the answer. "Why isn't the balance visible?" gets a much better response than "fix everything".
Now
🐛
Step 6 — Start the bug hunt
You're ready. Here's what to do.
9
Find bugs, fix them, write them down

First, everyone does one together. Your facilitator will walk through a made-up example bug as a class — this teaches you the exact method before you touch the real dashboard. Follow along at how-to-find-fix-bugs.html.

Then you're on your own. The NovaPay dashboard has 10 bugs hidden across the HTML, CSS, and JavaScript. Some you can spot just by looking at the page. Others you'll only find by using it. Some are in the code.

For every bug you find, write down three things:

  • What was wrong
  • How you found it
  • What you changed to fix it
📝Use the Bug Test Plan to log these — open it in a new tab alongside your Codespace. It saves automatically as you type.
🔍Start by just looking at the page preview. Something should look obviously wrong before you even touch the code.
10
How to make a fix and see it work

Click on bank-dashboard.html in the file panel to open the code. Find the bug, change it, then save with Ctrl+S (or Cmd+S on Mac).

Switch back to the preview tab — because of Live Server, the page will refresh automatically and you'll see if your fix worked.

🖥️Press F12 to open the browser console. If something's broken in the JavaScript, you'll see a red error message in there — it's a useful clue.
🚀
You're all set. Good luck.
There are 10 bugs. 3 are easy, 3 are medium, 3 are hard, and 1 is a stretch. At the end you'll explain what you found to the group — so make sure you understand each fix, not just the code.
