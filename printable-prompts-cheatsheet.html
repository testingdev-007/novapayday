Prompts Cheat Sheet
Every vetted prompt across the whole day, in one place — none of these give away a real bug
🐛Bug Hunt — hand these out if a group is stuck
"Are there any bugs in this code?"
"I clicked this button and nothing happened — what could cause that?"
"What does this function do?"
"Why might a number show up as NaN instead of a value?"
"How do I check if two IDs used in different places actually match?"
"Can you explain this CSS rule to me?"
⚡Level Up — Round 1, Fix the Bug
"Can you review this function for bugs? Pay attention to how the interest rate is being used."
If stuck after that: "Is the 5% rate being treated as 5, or as 0.05?"
🏗️Feature Creation — Y9–Y10
"Why isn't my progress bar changing width?"
"My button click isn't doing anything — what's wrong with this function?"
"Explain what getElementById does in plain English"
🏗️Feature Creation — Y11
"Review this function for edge cases I might have missed"
"Suggest a way to make this code more readable"
🏗️Feature Creation — Y12–13
"Are there any bugs or inefficiencies in this code?"
"How would you refactor this to be more maintainable?"
✅Anytime — universally useful
"What problem am I trying to solve right now?"
"I expected X to happen when I did Y, but Z happened instead. Why?"
"The console shows this error: [paste it]. What does it mean?"
All of these are generic technique prompts — none of them describe a specific real bug's symptom. Safe to hand out freely.
