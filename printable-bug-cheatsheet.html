Bug Cheat Sheet
All 10 bugs, one page. Keep this in your hand during the Bug Hunt hour.
Easy — visible on the page
Medium — found by using it
Hard — need the code/console
Stretch — missing logic
#BugWhat goes wrongThe fix
1 Missing closing tag Page layout collapses — everything below looks broken/nested wrong Add missing </div> after the balance footer
2 Invisible balance Balance text is same colour as its background color: #0F1340 → color: #FFFFFF
3 Wrong transaction sign Coffee purchase shown as +£3.80 (income, green) instead of an expense Change class credit → debit, amount to −£3.80
4 Wrong input type Withdrawal field accepts letters — breaks the calculation type="text" → type="number"
5 Button typo Withdraw button does nothing at all, no error onlick → onclick
6 Wrong operator Withdrawing money increases the balance balance + amount → balance - amount
7 Element ID typo Console shows TypeError: null — balance never updates on screen "balence-display" → "balance-display"
8 NaN on empty input Clicking Withdraw with nothing entered shows £NaN Add a check: if (isNaN(amount) || amount <= 0) return;
9 Wrong interest formula 5% rate treated as 5 instead of 0.05 — answer is 100× too big * rate → * (rate / 100)
10 No overdraft check Can withdraw more than the balance — goes negative with no warning Add a check: if (amount > balance) return; before deducting
If someone asks Nova to "fix everything at once": it won't get all 10 anyway — bugs 8, 9, and 10 are missing logic, not broken code, and Nova is designed to hint rather than dump full fixes during this phase. If it happens, make it a teaching moment: stop the room, look at what it missed together, ask "why do you think it caught some but not others?"
Full write-up of each bug — including why it matters and the fully corrected code — is in facilitator-reference.html and bug-answer-key.html if you need more than this sheet gives you.
