Session Day Script
Hold this. Follow it top to bottom. Every line you need to say is already written.
You don't need to know the answers today. Your job is to run this script and point people at Nova when they're stuck on something technical. Every "say this" line below is exactly what to say, word for word if you want it. Ticking a box doesn't mean it went perfectly — it means you did the step. That's enough.

Hour 1 Bug Hunt 0:00–1:05
0:00Welcome15 min
Share the repo URL on screen
Ice breaker out loud: "What's one thing that annoys you about a bank app?"
Pair people up — mix ages where you can
Say this
"Today you're going to build a real feature for a banking app — from idea to working demo. We'll start by doing what every developer does first: fix what's broken."
0:15Copilot demo15 min
Type a comment, let Copilot suggest, press Tab
Open Copilot Chat, ask it to explain some code
Say this
"Copilot is a very fast autocomplete that's read most of the internet. It's not always right. Your job is to understand the problem — Copilot helps you write it faster."
0:30Bug tutorial — everyone together10 min
Everyone opens how-to-find-fix-bugs.html and follows the worked (fake) example together
This is deliberately not one of the real 10 bugs — it teaches the method (Look → Use → Read → Fix → Test) before anyone touches the real dashboard.
0:40Bug hunt — on your own20 min
Put bug-hunt-screen.html on the projector, leave it up
Remind them to log finds in bug-test-plan.html (or the paper version) as they go
Step back — let them use Nova in Copilot Chat
10 bugs total. Easy ones are visible on the page. Harder ones need the console (F12). Nova gives hints, not answers — that's deliberate, don't worry if students seem to be getting nudged rather than told.
1:00Share out5 min
Ask 2–3 people: "What did you find? How did Copilot help?"
Say this
"That's the debugging loop — notice, investigate, fix, test. Copilot speeds up the middle part, but you're still the one running the loop."
Bridge Level Up ⚡ 1:05–1:35
1:05The reveal + concepts8 min
Open level-up-screen.html, click through slides 1–4
Say this
"You just used GitHub Copilot to debug a real banking app. It was trained on over a billion lines of code — more than any human could read in a lifetime. And it still gets things wrong sometimes. That matters."

Say this

☕ Break Comfort Break 1:35–1:50
1:35Comfort break15 min
Toilets, water, stretch legs — genuinely just a break
Bridge Feature Tutorial, Brainstorm & Plan 1:50–2:35
1:50Feature tutorial — everyone together20 min
Everyone opens how-to-build-your-feature.html and follows it together — a Savings Tracker, built from a genuinely blank file
This teaches every technique they'll need: page skeleton, colours, header, forms, then the logic. Same idea for everyone, on purpose — the brainstorm right after is where they pick something different.
2:10Brainstorm15 min
Slides 1–2 on brainstorm-screen.html — popcorn round, then pick an idea
Stuck group? Point at the back-pocket gallery on slide 2 — just not the Savings Tracker, they've already built that one in the tutorial.
2:25Plan on paper10 min
Slide 3 (4 questions) then slide 4 (timer) — keyboards down, paper only
Say this
"Keyboards down. Every minute you plan saves five minutes of confused coding. Your sketch becomes your Copilot prompts."
🍽️ Lunch Lunch & Accessibility 2:35–3:10
2:35Lunch30 min
Accessibility activities happen during this window — no content to run
Lunch sits here on purpose — before any feature creation starts, not mid-way through it, so nobody's mid-flow when they break.
3:05Accessibility discussion5 min
Say this
"You just spent lunch thinking about accessibility. Before we start building — does anything change how you'd want your feature to work? Would everyone be able to use it?"
1–2 quick reactions, keep it tight — this is only 5 minutes
Main event Feature Creation + Show & Tell + Feedback 3:10–5:00
3:10Feature creation85 min
Open milestone-screen.html, start its timer
Everyone creates a new file for their own idea and copies the colours/header across from practice-feature.html (built in the tutorial) to keep the NovaPay look
Say this — the method
"One: write a comment describing the next small thing. Two: let Copilot suggest, press Tab. Three: save, check Live Server. Four: if it's wrong, ask Nova why. Small steps — comment, code, check."
Structure, logic, styling, and testing all happen in this one continuous block — no separate checkpoint or testing slot, so pace it yourself. Rough guide: ~3:35 structure done, ~4:10 styled and working, ~4:25 tested (code freeze, try to break it on purpose), 4:35 done.
At ~4:00 — hard scope call for anyone not working yet: "Strip it back. One input, one button, one number on screen. Get that working, then add back." Say it to the whole room, not just the stuck group.
Groups that finish everything: milestone screen's right panel has stretch goals by year group — click the Y12–13 tab for the hardest ones.
4:35Show & tell15 min
Each group: 2 min. Room answers "what did you like?" after each
If a demo breaks live: "Congratulations — a live demo failure. That's the most authentic developer experience of the day." Then let them show it in the editor instead.
Your closing
"Two hours ago you built one feature together, step by step. Then you described your own idea, Copilot helped you build it, you tested it, you fixed it, you shipped a demo. That loop — describe, build, test, fix — is the actual job. The tools will keep changing. The loop won't."
4:50Feedback10 min
"One word for how today felt" — go round the room fast
Feedback form or QR code on screen if you have one
Keep it short — energy is naturally dropping after demos. A fast, light close beats a thorough one nobody engages with.
If you're stuck on something technical mid-session: open your own Copilot Chat, paste the student's problem in, and work through Nova's answer together, out loud. "I don't know, let's find out" is better teaching than knowing the answer.
Full detail, rescue plans, and every back-pocket idea are in build-phase-guide.html and session-plan.html if you need more than this script gives you. This page is deliberately the short version — everything you need to run the room without looking anything up.
