The 10 Bugs
01
Missing closing tag
HTMLEasy
What goes wrong
The page layout collapses. Stats row and cards below appear nested inside the hero card — broken spacing throughout.
How to find it
Open the preview — the layout looks wrong immediately. Search for balance-hero and count opening vs closing div tags.
The fix
      <div class="balance-footer">
        <div class="account-name">Alex Chen</div>
        <div class="account-pill">•••• 4821</div>
      </div>
-                             ← closing </div> missing
+     </div>                  ← add this line
02
Invisible balance
CSSEasy
What goes wrong
The balance is in the HTML but completely invisible — dark text on a dark background.
How to find it
Balance section is blank. Search CSS for .balance-amount and compare the colour to the card background.
The fix
.balance-amount {
-   color: #0F1340;  /* same as card background */
+   color: #FFFFFF;  /* white — visible on dark card */
}
03
Wrong transaction sign
HTMLEasy
What goes wrong
Costa Coffee shows as income (+£3.80, green). A coffee purchase is money out, not money in.
How to find it
Look at the transactions list — the coffee entry is green with a plus. Find it in the HTML.
The fix
- <div class="tx-amount credit">+£3.80</div>
+ <div class="tx-amount debit">−£3.80</div>
04
Wrong input type
HTMLMedium
What goes wrong
Withdrawal field accepts any text including letters. Typing "hello" corrupts the balance with NaN.
How to find it
Try typing a letter into the field — it accepts it. Look at the input's type attribute.
The fix
- <input type="text" id="withdraw-amount" placeholder="0.00">
+ <input type="number" id="withdraw-amount" placeholder="0.00">
05
Button typo — does nothing
HTMLMedium
What goes wrong
Withdraw button looks fine but clicking it does absolutely nothing — silently fails.
How to find it
Click the button — nothing happens. Read the HTML attribute carefully: onlick vs onclick.
The fix
- <button class="btn" onlick="makeWithdrawal()">Withdraw</button>
+ <button class="btn" onclick="makeWithdrawal()">Withdraw</button>
06
Wrong operator — withdrawal adds money
JSMedium
What goes wrong
Balance increases when you withdraw. The more you take out, the richer you get.
How to find it
After fixing bug 5, withdraw an amount — balance goes up. Read makeWithdrawal().
The fix
- balance = balance + amount;
+ balance = balance - amount;
07
Element ID typo — crashes the update
JSHard
What goes wrong
JS throws TypeError: Cannot set properties of null in the console. Balance on the card never updates.
How to find it
Press F12 → Console and trigger a withdrawal. Red error appears. Compare the ID in JS to the one in HTML.
The fix
- document.getElementById("balence-display").textContent = ...
+ document.getElementById("balance-display").textContent = ...
08
NaN on empty input
LogicHard
What goes wrong
Click Withdraw with no amount entered — balance shows £NaN and message reads Withdrawn £NaN.
How to find it
Click Withdraw without entering anything. Then read the function — there's no if check before the calculation.
The fix — add before the calculation
+ if (isNaN(amount) || amount <= 0) {
+   errorEl.style.display = "block";
+   errorEl.textContent = "Please enter a valid amount.";
+   return;
+ }
09
Wrong interest formula
JSHard
What goes wrong
Rate not converted to decimal. £1,000 at 5% should earn £50/year — buggy formula returns £600 (100× too high).
How to find it
Enter a principal and rate, check against a phone calculator — massively wrong. Read calculateInterest().
The fix
- const interest = principal * rate * 12;
+ const interest = principal * (rate / 100) * 12;
10
No overdraft protection
LogicStretch
What goes wrong
You can withdraw more than your balance. No real bank allows this without an agreed overdraft.
How to find it
Withdraw more than £1,250 — balance goes negative. Read the function: there's no if (amount > balance) check.
The fix — add after the NaN check
+ if (amount > balance) {
+   errorEl.style.display = "block";
+   errorEl.textContent =
+     "Insufficient funds. Balance: £" + balance.toFixed(2);
+   return;
+ }
Fully corrected makeWithdrawal()

What the function looks like once bugs 6, 7, 8 and 10 are all fixed.

makeWithdrawal() — corrected
function makeWithdrawal() {
  const successEl = document.getElementById("wd-success");
  const errorEl   = document.getElementById("wd-error");
  successEl.style.display = "none";
  errorEl.style.display   = "none";
  const amount = parseFloat(document.getElementById("withdraw-amount").value);

  // Bug 8 fix: validate input
  if (isNaN(amount) || amount <= 0) {
    errorEl.style.display = "block";
    errorEl.textContent = "Please enter a valid amount.";
    return;
  }

  // Bug 10 fix: overdraft check
  if (amount > balance) {
    errorEl.style.display = "block";
    errorEl.textContent = "Insufficient funds. Balance: £" + balance.toFixed(2);
    return;
  }

  // Bug 6 fix: subtract, not add
  balance = balance - amount;

  // Bug 7 fix: correct element ID
  document.getElementById("balance-display").textContent =
    "£" + balance.toFixed(2);

  successEl.style.display = "block";
  successEl.textContent =
    "Withdrawn £" + amount.toFixed(2) + ". New balance: £" + balance.toFixed(2);
}
