Setup Guide
Print this out. Tick each box as you go. That's the whole job.
Before you start: you don't need to understand GitHub, Copilot, or Codespaces to finish this list. You just need to click the things this page tells you to click, in order. If a step doesn't make sense, that's normal — do it anyway, it'll make sense once it's done. Nothing here is fragile; you can't break anything permanently.
Target 1 — Org & seats
Thu 30 Jul
Target 2 — Run-through
Fri 31 Jul
1
Your GitHub account
Skip if you already have one
Go to github.com → click Sign up → enter email, password, username
Check your email for a verification code → enter it
2
Create the organisation
This is separate from your personal account — it sits alongside it
Click the + icon top right → New organisation
Choose the Free plan
Give it a short, simple name — write it here so you don't forget:  
3
Turn on Copilot, buy 2 seats
Go to your organisation page → Settings tab → find Copilot in the left menu
Click Enable GitHub Copilot → choose Business → set seats to 2
Find the Policies section → set Copilot access to All repositories
⚠ Don't skip this. If it's set to "org repos only," Copilot silently won't work later — with no error message to tell you why.
4
Build the workshop repo
Click + → New repository → owner = your personal account (not the org) → name it novapay-workshop → set Public → tick Add a README
Click Add file → Upload files → drag in bank-dashboard.html, starter-template.html, and challenge.js → Commit changes
Click Add file → Create new file → in the filename box, type exactly:
.devcontainer/devcontainer.json
Then paste in the contents of your devcontainer.json file → Commit new file
Go to repo Settings → tick Template repository
5
Install Nova (your AI mentor)
One file, one paste — nothing to install on your computer
On the same repo, click Add file → Create new file
In the filename box, type exactly this — copy it if you can, don't retype from memory:
.github/copilot-instructions.md
⚠ This filename is the one thing in the whole setup that must be perfect. One typo and Nova simply never switches on — with no error to warn you.
Open copilot-instructions.md from your materials pack → select all (Ctrl/Cmd+A) → copy → paste the whole thing into the big text box on GitHub
Scroll down → click Commit changes
6
Give yourself a Copilot seat
Org → Settings → Copilot → Seat management → Add users → select yourself
That's Target 1 done. Org exists, Copilot's on, 2 seats bought, repo built with all 3 files (bank-dashboard.html, starter-template.html, challenge.js) plus Nova installed, your seat assigned. Nothing left to click until Friday.
7
Test the whole thing yourself
This is the step that actually proves it works — do this on Friday
Go to your repo → click Use this template → Create a new repository → name it test-novapay
On the new repo, click Code → Codespaces tab → Create codespace on main → wait (1–2 minutes first time)
Right-click bank-dashboard.html in the file list → Open with Live Server → confirm the banking dashboard actually appears
Click the Copilot icon on the left sidebar → in the chat box, type exactly:
Who are you?
It should describe itself as a NovaPay mentor — not a generic "I'm GitHub Copilot."
⚠ Generic answer instead of "Nova"? Go back to Part 5 and check the filename character by character.
Ask it something like "why isn't the balance showing?" — it should nudge you with a hint, not just hand you the fixed code straight away
Open starter-template.html — confirm it opens and looks sensible
Go to the test repo's Settings → scroll to the bottom → Delete this repository
That's Target 2 done. You've now personally seen every part of the participant journey work. You are ready.

If you want a real second person (not just yourself) in Friday's test, they need to accept an org invite before you can give them a seat. Send that invite today or tomorrow — email replies aren't instant, and Thursday is too late to be sure.
