🎯 What's actually left for you to do
Everything else is written. These four things require your actual GitHub account and can't be done for you — but each is quick, and they're all in the setup guide with exact steps.
1
Create your GitHub org and enable Copilot seats. ~15 minutes. Full walkthrough in facilitator-setup-guide.html, Parts 1–4.
2
Upload 4 files to your template repo: bank-dashboard.html, starter-template.html, challenge.js, and the .devcontainer/devcontainer.json config. ~5 minutes. Setup guide Part 5.
3
Install Nova — create .github/copilot-instructions.md and paste in the contents of copilot-instructions.md. ~2 minutes. Setup guide, new "Install Nova" section, step-by-step with exact clicks.
4
Test the whole flow yourself once. Use the template, open a Codespace, open Live Server, open Copilot Chat, type "Who are you?" and confirm Nova responds. ~10 minutes. Setup guide Part 7.
Total time to fully ready
About 30–35 minutes of clicking through the setup guide, once, before the session. None of it requires coding knowledge — every step is a specific button to click.
