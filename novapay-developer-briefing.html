NovaPay — technical facilitator briefing

NovaPay is a full-day workshop where UK students aged 13–18 debug a fake banking app and then build their own feature, both using GitHub Copilot. This doc skips the pedagogy and goes straight to how the thing actually works, what breaks, and how to fix it fast in front of a table of students.

The structure of the day
Mark runs the room — the clock, the slide decks, every phase transition. You own one small table of students for the entire day. That's the key thing to understand: you're not roaming backup, you're the only guide your table has, from the first bug to the final demo. When Mark moves the whole room from Brainstorm to Plan, it's you who actually gets your table there.
Accounts & setup — not your job
Every student account, repo, and Codespace is already set up before you arrive. You won't provision anything. Know enough about the stack to troubleshoot (see below), but if an account is genuinely broken, that's an escalation to Mark, not something to fix from scratch mid-session.

02The Stack

Context so you can help troubleshoot when something looks broken at your table. Every student: personal GitHub account → repo from a template → GitHub Codespace → VS Code in the browser, with GitHub Copilot and a custom instructions file.

Not your job
Account creation, repo templates, and Codespace provisioning are all set up in advance. If a student's account genuinely isn't working, that's an escalation, not something to debug from scratch on the day.
03How Nova Works

Nova isn't a separate product — it's Copilot Chat with a repo-level .github/copilot-instructions.md that changes behaviour based on phase. GitHub Copilot reads this automatically for Chat, inline completions, and Agent mode in VS Code.

Instructions constrain Nova to hints only — it should ask leading questions ("what does this function return when the input's empty?") rather than hand over a fix. This is deliberate friction: the point is the debugging method, not the fixed file.

Expected, not broken
Students getting nudged rather than told the answer is the instructions working as designed. Don't "fix" this if a student complains Nova won't just tell them.

Instructions switch to generative — Nova builds with the student. Agent mode specifically (not Ask/Chat) is action-biased by default, which needed an explicit hard rule in the instructions file:

make ONE real, scoped fix, then STOP
and explain what you changed and why —
never refuse outright, never rewrite
everything in one pass
History here
The first version of this rule said "don't just fix everything" without also saying "but do fix something" — Nova over-corrected and started refusing to make any fix at all. If you're editing this file, test both directions: too eager AND too refusing.

The reliable check is the References list under a Copilot Chat response — expand it and confirm .github/copilot-instructions.md appears. Don't rely on judging tone or "does this feel restrictive" — that's subjective and slower to debug against.

If it's missing: the file may not exist at the exact path, the Codespace may not have pulled the latest commit (see Failure Modes), or the file was added after the Codespace was created and it needs a container rebuild.

08Accounts & Billing

Worth knowing if a student or co-facilitator asks why Copilot "stopped working" mid-session.

Copilot Free — 50 chat messages/month
As of GitHub's June 2026 usage-based billing shift, personal accounts on the Free tier get 2,000 code completions but only 50 chat requests a month. A day this chat-heavy (bug hints, three Level Up rounds, 85 minutes of iterative building) can burn through that before lunch on a brand-new free account. If students are on paid Pro/Pro+ seats, this doesn't apply — but paid tiers now run on an AI Credit allowance too ($10 Pro = $10/month in credits), not literally unlimited, so heavy Agent-mode use across a full day is still worth a mental note.
GitHub Education Student accounts
A different path: unlimited code completions, but chat/agent usage is still capped, and — since June 24, 2026 — Free and Student tiers use auto model-selection only, no manual model picker. Don't build a live demo around picking a specific model on these accounts.
