Plan it on paper first — 5 minutes
Answer these 4 questions before you write any code
Q1
What does it do?
One sentence. If you can't describe it in one sentence, it's too complicated.
e.g. "It shows how close you are to a savings goal and how much you still need."
Q2
What does the user see?
Draw boxes on paper — don't code yet. A heading, some inputs, a result area.
e.g. A text input, a number input, a progress bar, and a label underneath.
Q3
What are the inputs?
What does the user type in or select? List them all — name them clearly.
e.g. goalName (text), targetAmount (number), savedSoFar (number)
Q4
What does it output?
What does the user see after they click? A number, a bar, a message, all three?
e.g. A progress bar at 60%, "£40 left to save", and a message if the goal is reached.
