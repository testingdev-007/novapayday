Full-day workshop briefing

Everything about running NovaPay

A full-day, in-person workshop teaching UK students to use GitHub Copilot by debugging and extending a fake banking app. Students spend the morning fixing planted bugs, then the afternoon building their own feature from scratch — both guided by Nova, a customised Copilot Chat persona.

02Logistics & Setup

Every student uses their own personal GitHub account — not an organisation account, since Business self-serve signup was paused when this was built. Each creates a repo from a template, then opens it in a GitHub Codespace — a cloud dev environment that works on any device, including school machines and iPads.

04How Nova Works

Nova is just GitHub Copilot Chat with a custom .github/copilot-instructions.md file in each student's repo. It behaves differently depending on which phase of the day it is.

During the bug hunt, Nova gives hints, not answers. It won't just fix the bug for a student who pastes in broken code.

Verify it's working: check the References list on a Copilot Chat response — click it to confirm the instructions file was actually used. More reliable than judging by tone alone.

During feature creation, Nova helps build — but Agent mode (distinct from Ask/Chat) is action-biased, so it needs a hard rule: make one real fix, then stop and explain.

The first version of that rule caused Nova to refuse fixes outright — overcorrected. It was rewritten to require action, just paced action.

If one student's Nova is too restrictive
It only affects that student — each has their own repo. Rename their .github/copilot-instructions.md on github.com, rebuild their Codespace, and Copilot reverts to normal for them only.

06The 10 Planted Bugs

All in bank-dashboard.html. Bugs 3, 8, 9, 10 are logic/data errors rather than syntax errors — if a group asks Copilot to "fix everything at once," it will likely miss these. Worth using as a live teaching moment if it happens.

#LevelBug
1EasyMissing closing </div> tag
2EasyBalance text colour matches background (invisible)
3EasyCoffee purchase shows as credit instead of debit
4MediumInput type is text instead of number
5MediumButton typo: onlick instead of onclick
6MediumWrong operator — adds instead of subtracts on withdrawal
7HardElement ID typo (balence-display vs balance-display)
8HardNaN shown on empty input — missing isNaN() check
9HardWrong interest formula — missing /100
10HardNo overdraft check
