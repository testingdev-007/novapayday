Target 1 — Org and 2 seats live
Deadline: Thursday 30 July
Pure GitHub admin — every step is a specific button to click. Full detail for each is in facilitator-setup-guide.html; this is the condensed order to work through.
1
Create your GitHub account
Skip entirely if you already have one — just make sure you're signed in.
2
Create the organisation
GitHub → + icon → New organisation → Free plan. This is separate from your personal account and sits alongside it.
3
Enable Copilot Business, buy 2 seats
Org → Settings → Copilot → Enable → choose Business → 2 seats. This is the only recurring cost — see the cost breakdown below.
4
Set the repo policy to "all repositories"
Same Copilot settings page → Policies → set Copilot access to all repositories, not just org-owned ones.
⚠ Miss this and Copilot will silently not work once participants are in their own personal repo copies. Easiest step to accidentally skip.
5
Create the template repo, upload 3 files
New public repo → upload bank-dashboard.html, starter-template.html, challenge.js, and .devcontainer/devcontainer.json (the last one needs its own folder — see the setup guide for the exact filename trick). Then tick Template repository in Settings.
6
Install Nova
Add file → Create new file → filename exactly .github/copilot-instructions.md → paste in the full contents of copilot-instructions.md → Commit.
⚠ The filename must be exact, including the leading dot and the slash. A typo here means Nova never activates and Copilot just behaves generically — with no error message telling you why.
7
Assign one seat to yourself
Org → Settings → Copilot → Seat management → Add users → yourself. Leave the second seat unassigned for now — you don't need a real second person until Friday.
By end of Thursday
Org exists · 2 seats purchased · 1 assigned to you · repo built with all 3 files · Nova installed and committed · policy set to all repos.
🧪
Target 2 — Full run-through
Deadline: Friday 31 July
Walk the entire participant path yourself, end to end, using your own seat. This is the step that actually proves everything works — not just that the files exist.
1
Create a test copy from your template
Your repo page → Use this template → Create a new repository → call it something like test-novapay.
2
Open a Codespace on it
Code → Codespaces tab → Create codespace on main. Time how long it takes to load — worth knowing for the real day.
3
Open the dashboard in Live Server
Right-click bank-dashboard.html → Open with Live Server → confirm the buggy NovaPay dashboard actually renders in a preview tab.
4
Confirm Nova is actually active
Open Copilot Chat → type exactly: Who are you?
⚠ If it gives a generic "I'm GitHub Copilot" answer instead of describing itself as a NovaPay mentor, Nova isn't active — go back and re-check the exact filename from Target 1, Step 6.
5
Try fixing one bug via Chat
Ask Nova something like "why isn't the balance showing?" — confirm it nudges with a hint rather than just handing over the fixed line straight away (that's the Bug Hunt restriction working as designed).
6
Check the starter template is there
Open starter-template.html in the file list — confirm it opens and the TODO comments are intact.
7
If your second person is ready — test them too
Have them repeat steps 1–6 independently at the same time, on their own seat, to confirm two people can use the repo simultaneously without conflict.
8
Delete the test repo
Settings → scroll to the bottom → Delete this repository. Keeps things tidy — your real template repo is untouched.
By end of Friday
You've personally walked the full participant journey once and confirmed Nova responds in character. That's the single check that matters most — everything else on the day flows from Nova actually working.
⏰
The one thing at genuine risk
Org invites need acceptance before a seat can be assigned
If you want a real second person (not just yourself) in Friday's run-through, they need to accept your org invite before you can give them a seat — and that round-trip depends on how quickly they check email. Send that invite today or tomorrow, not Thursday, so there's no risk of Friday's test being solo-only by accident.
